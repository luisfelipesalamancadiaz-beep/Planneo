PREGUNTAS FRECUENTES

Antes de empezar

¿Necesito crear una cuenta?

No. Puedes empezar sin registrarte. Tus datos de agenda se guardan en el almacenamiento de este navegador.

¿Puedo cambiar mi configuración después?

Sí. La configuración inicial se muestra la primera vez; después puedes cambiar tus preferencias desde la sección de configuración de Planneo.

¿Puedo usar Planneo en mi celular?

Sí, la interfaz está pensada para adaptarse a pantallas de computadora y de celular. Puedes abrirla desde el navegador.

¿Mis datos se sincronizan automáticamente entre dispositivos?

No. Como los datos se guardan en el navegador de cada dispositivo, no se sincronizan automáticamente entre celulares y computadores.

¿Qué pasa si borro los datos del navegador?

Podrías perder las tareas, notas y preferencias guardadas en ese navegador. Evita borrar sus datos si quieres conservar tu información.

INFORMACIÓN CLARA

Privacidad y almacenamiento

Datos guardados localmente. Las tareas, notas, hábitos y preferencias de Planneo se guardan en el almacenamiento local del navegador que estás usando. No se crea una cuenta ni se envían esos datos a un servidor propio de Planneo para sincronizarlos.

Sincronización y eliminación. La información no se sincroniza automáticamente con otros dispositivos. Si borras los datos del sitio o el almacenamiento del navegador, puedes perder la información guardada.

Conexiones externas. Planneo puede cargar recursos de terceros necesarios para algunas funciones o estilos, como bibliotecas y fuentes. Esos proveedores pueden recibir datos técnicos de la conexión, como la dirección IP, según sus propias políticas.

Notificaciones. Si activas los recordatorios, el navegador te pedirá permiso. Puedes gestionar ese permiso desde la configuración del navegador.
